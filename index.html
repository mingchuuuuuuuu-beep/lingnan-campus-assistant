One-Page Architecture: RAG Workflow Pipeline

Why not plain LLMs? General models hallucinate outdated dates and rules. Our system uses closed-book RAG to ensure every answer is grounded in official university documents.

Technical Specs & Project Commitments:

• Zero-Cost Operation ($0 Cost): Powered by Google Gemini Free Quota and hosted on GitHub Pages free CDN.

• Strict Anti-Hallucination & Auto-Language Matching: Chinese queries are answered in Traditional Chinese; English queries are answered in English. Missing facts are honestly declined.

• Disclaimer: This is a CCC8015 student project prototype, not official university staff. Confirm important decisions with Registry/OSA.

Security & Architecture Trade-off (Key Management):

• Client-Side Static Hosting Trade-off: A zero-cost GitHub Pages app cannot hide keys behind server environment variables. The primary defense is Google Cloud HTTP Referrer Restriction (authorized only for https://mingchuuuuuuuu-beep.github.io/*).

• Demo Key Rotation Lifecycle: The demo key uses free-tier quota (no credit card bound) and is scheduled for immediate revocation and regeneration in Google AI Studio following the presentation.

• Production Security Roadmap: Full commercial deployment will introduce a lightweight serverless reverse proxy (e.g. Cloudflare Workers or Supabase Edge Functions) to store keys securely in server environment secrets.
